## Student Ranking System

A Python-based project that ranks students based on their marks using sorting algorithms and efficiently retrieves top-K students using heap data structures.

## Features
- Add student records with marks
- Generate ranked student lists using sorting
- Retrieve top-K students using heap
- Modular and object-oriented design

## Technologies Used
- Python
- Data Structures & Algorithms
  - Sorting
  - Heaps

## How to Run
Run "python3 main.py" in terminal
